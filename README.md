# RuneLite plugins

Source for my RuneLite plugin hub plugins. Each one lives on its own branch.

| Plugin | Branch | What it does |
|---|---|---|
| The Other Half | [`the-other-half`](../../tree/the-other-half) | Resets the skills tab at 92 so you climb 1-92 twice |

This branch is the unmodified [example plugin](https://github.com/runelite/example-plugin) template, so a new plugin starts by branching from here.
